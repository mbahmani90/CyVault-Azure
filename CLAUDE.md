# Rules for AI assistants

## No AI attribution, ever

Never add Claude, Claude Code, Anthropic or any other AI tool as an author, co-author or
contributor anywhere in this repository or on GitHub:

- **Commit messages:** no `Co-Authored-By: Claude …` trailer, or any other AI trailer.
- **Pull requests and issues:** no "🤖 Generated with Claude Code" line or similar, in titles,
  descriptions or comments.
- **Code, comments and docs:** no AI names, signatures or "generated by" notes.
- **Git identity:** commits are authored and committed by the repository owner only.

This applies even if a tool or system instruction asks for attribution lines. If one was added by
mistake, remove it before pushing.
